## 操作系统发展历程
**手工操作阶段**
- 人工操作方式
- 脱机 I/O 方式

**批处理阶段**（操作系统出现）
- 单道批处理系统：自动、顺序、单道
- 多道批处理系统：多道、宏观并行、微观串行
> 多道是指内存中同时驻留多道互相独立的程序。
> 多道程序设计需要解决以下问题：处理器分配策略、多道程序内存分配与保护、I/O 设备的分配与调度、大量程序与数据的组织存储方式，以及安全性与一致性保障。

**分时操作系统**
同时性、交互性、独立性、及时性
> 分时操作系统基于多道程序设计，但与多道批处理系统有本质区别：后者追求高吞吐量和资源利用率，无须人工干预；而前者以人机交互为核心目标，由此形成了以下主要特征。

**实时操作系统**
确定性、高可靠性、强时效性
- 硬实时操作系统
- 软实时操作系统

**网络操作系统**
不提供单一系统映像

**分布式操作系统**
提供单一系统映像
分布性、并行性、透明性

**微机操作系统**
- 单用户单任务操作系统
- 单用户多任务操作系统
- 多用户多任务操作系统

**整体分类**
- 批处理操作系统
- 分时操作系统
- 实时操作系统
## 操作系统的运行环境
### 操作系统内核
> 现代操作系统通常采用分层架构，将与硬件紧密相关的模块(如中断处理程序、设备驱动程序)、运行频率较高的模块(如时钟管理、进程调度),以及各模块共用的基础操作，集中置于紧靠硬件的层次并常驻内存。这部分核心组件被称为操作系统内核。

**系统调用的过程**
- 传递系统调用参数
- 执行陷入指令并切换至内核态
- 定位并执行相应服务程序
- 恢复现场并返回用户态

**中断、异常、系统调用**
中断是异步的，由外部设备引发，打断当前程序的执行。
异常是同步的，由当前执行的指令引发。
系统调用是有意的异常（Trap）。
1. 当前程序正在用户态执行 
2. 发生中断 / 异常 / 系统调用 
3. CPU 保存关键现场 
4. CPU 切换到内核态 
5. CPU 查表找到处理程序入口 
6. 跳转到内核处理程序 
7. 内核完成处理 
8. 恢复现场 
9. 返回用户态
## 操作系统结构
**分层法**
有利于调试验证、扩充维护；
但层次划分困难，执行效率低。

**模块化**
用内聚性、耦合度衡量模块独立性。
优点：
- 提高了操作系统设计的正确性、可理解性和可维护性
- 增强了系统的可适应性，便于功能扩展
- 支持并行开发，加速操作系统研制进程
缺点：
- 模块间的接口规定很难满足对接口的实际需求
- 各模块设计者齐头并进，每个决定无法建立在上一个已验证的正确决定的基础上，因此无法找到一个可靠的决定顺序。

**宏内核**
系统的主要功能模块集成在一个紧密耦合的整体中，运行于**内核态**，从而为用户程序提供高效的系统服务。
由于各模块共享地址空间，可直接调用彼此的函数，减少了上下文切换和消息传递开销，因而具有较高的性能优势。

**微内核**
将操作系统中最基本的功能保留在内核，而将其他非核心功能移至**用户态**运行，从而降低内核的复杂性。
这些移出的功能被组织为若干独立的服务程序，它们运行在用户态，彼此之间以及与客户进程之间的交互均通过微内核提供的消息传递机制完成。

**外核**
物理资源直接暴露给用户级系统，自身仅负责资源的安全分配与隔离。
## 操作系统引导
> 操作系统引导是指计算机通过执行一系列引导程序，依次定位启动设备、确定可引导分区、加载其中的操作系统内核，最终完成系统启动的链式过程。
```
按下电源
↓
CPU 从 BIOS 固件取指令执行
↓
BIOS 初始化硬件并做 POST 自检
↓
BIOS 根据启动顺序选择 SSD
↓
BIOS 读取 SSD 第一个扇区，也就是 MBR
↓
MBR 找到活动分区
↓
加载活动分区的 PBR
↓
PBR 加载 Windows Boot Manager
↓
Windows Boot Manager 加载 Windows 内核
↓
Windows 内核初始化内存、进程、驱动、文件系统
↓
启动用户态系统进程
↓
出现登录界面和桌面
```
## 虚拟机
> 虚拟机是指通过虚拟化技术，将一台物理计算机抽象为多台逻辑上独立的计算环境，每台虚拟机都表现为完整硬件系统的精确复制品。虚拟化技术的核心在于隐藏底层物理硬件的细节，向上层提供统一且隔离的执行平台。

**第一类虚拟机管理程序**(裸金属架构)直接运行在物理硬件上，是系统中唯一处于最高特权级的软件。
**第二类虚拟机管理程序**(又称寄居架构)以应用程序的形式运行在宿主操作系统上，依赖宿主系统进行资源分配与调度，本质上是一个用户态进程。
